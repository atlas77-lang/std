Struct core::type_info

struct core::type_info

Declared in src/reflection.atlas

Everything the compiler knows about a type. Obtained through type_of<T>().

The layout of this struct is tied to the compiler, so it will change alongside it.

Fields

align: uint64

Alignment of the type in bytes. Same value as align_of<T>()

field_count: uint64

Number of entries in field_names

field_names: [str]

Names of every field declared on the type

id: uint64

Unique id of the type. Same value as type_id<T>()

is_copyable: bool

Whether the type implements std::copyable

is_default: bool

Whether the type implements std::default

is_trivially_copyable: bool

Whether the type is tagged #[std::trivially_copyable]

mangled_name: str

Name of the type once mangled by the compiler. Mostly useful for debugging the C output

method_count: uint64

Number of entries in method_names

method_names: [str]

Names of every method declared on the type

name: str

Name of the type as written in the source code (e.g. std::vector<int64>)

size: uint64

Size of the type in bytes. Same value as size_of<T>()
