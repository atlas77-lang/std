src/libc.atlas

Structs

  • libc::FILE Opaque C file stream. You never build one yourself, `fopen` hands you a pointer to it.

Functions

  • libc::EOF Not really a libc function. Will become a constant later
  • libc::calloc Allocates a zeroed buffer of `nelem * elsize` bytes. Returns `null` on failure.
  • libc::errno Returns the current value of the C `errno`. Set by most libc functions when they fail.
  • libc::fclose Closes the given file stream. Returns `0` on success.
  • libc::feof Returns a non-zero value once the end of `f` has been reached.
  • libc::fflush Forces any buffered output of `f` to be written out. Returns `0` on success.
  • libc::fopen Opens the file at `path` with the given C mode string (`"r"`, `"w"`, `"a"`, `"r+"`...). Returns `null` on failure, in which case `errno` is set.
  • libc::fread Reads up to `nmemb` items of `size` bytes each from `f` into `buf`. Returns the number of items actually read.
  • libc::free Releases memory previously obtained from `malloc`, `calloc` or `realloc`. Passing `null` is a no-op.
  • libc::fseek Moves the position of `f` by `offset` bytes relative to `whence` (`0` = start, `1` = current position, `2` = end). Returns `0` on success.
  • libc::ftell Returns the current position of `f` in bytes, or `-1` on failure.
  • libc::fwrite Writes `nmemb` items of `size` bytes each from `buf` into `f`. Returns the number of items actually written.
  • libc::get_char Reads a single character from standard input. Returns `libc::EOF()` once there is nothing left to read.
  • libc::malloc Allocates `size` bytes of uninitialized memory. Returns `null` on failure.
  • libc::mem_cmp Compares the first `size` bytes of `a` and `b`. Returns `0` if they are equal, a negative value if `a` is lower, a positive one otherwise.
  • libc::memcpy Copies `size` bytes from `src` to `dest` and returns `dest`. The two buffers must not overlap.
  • libc::realloc Resizes the buffer behind `ptr` to `size` bytes, moving it if necessary. Returns `null` on failure.
  • libc::snprintf Writes `val` into `s` following the C `format` string, writing at most `size` bytes. Returns the number of bytes that would have been written if `size` was big enough.
  • libc::str_error Returns a human readable message for the given error code (usually the value of `errno()`).
  • libc::str_len Takes a `*const uint8` and returns its length as `uint64`.
  • libc::to_lower Takes a single character and returns its lowercase equivalent if it's an uppercase letter, otherwise returns the character unchanged.
  • libc::to_upper Takes a single character and returns its uppercase equivalent if it's a lowercase letter, otherwise returns the character unchanged.
