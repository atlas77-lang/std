src/math.atlas

Math utilities backed by the C standard math library.

Most functions come in two flavours: the float64 one and the float32 one, the latter with an f suffix (sqrt/sqrtf, floor/floorf…). The trigonometric and hyperbolic functions only exist for float32 for now. A few integer helpers (min, max, pow_i64) are written in atlas since C has no equivalent.

Functions

  • std::abs Absolute value of an `int32`.
  • std::abs_i64 Absolute value of an `int64`.
  • std::absf Absolute value of a `float32`.
  • std::absf64 Absolute value of a `float64`.
  • std::acos Arc cosine of `x`, in radians in `[0, pi]`. `x` must be in `[-1, 1]`.
  • std::acosh Inverse hyperbolic cosine of `x`. `x` must be greater or equal to `1`.
  • std::asin Arc sine of `x`, in radians in `[-pi/2, pi/2]`. `x` must be in `[-1, 1]`.
  • std::asinh Inverse hyperbolic sine of `x`.
  • std::atan Arc tangent of `x`, in radians in `[-pi/2, pi/2]`.
  • std::atan2 Arc tangent of `y / x`, in radians in `[-pi, pi]`, using the signs of both arguments to pick the right quadrant.
  • std::atanh Inverse hyperbolic tangent of `x`. `x` must be in `(-1, 1)`.
  • std::cbrt Cube root of `x`. Works for negative values too.
  • std::cbrtf `float32` version of `cbrt`.
  • std::ceil Rounds `x` up to the smallest integer not less than `x`. `ceil(2.2) == 3.0`, `ceil(-2.2) == -2.0`.
  • std::ceilf `float32` version of `ceil`.
  • std::copysign `float32` version of `copysignf64`.
  • std::copysignf64 Returns `x` with the sign of `y`.
  • std::cos Cosine of `x` (in radians).
  • std::cosh Hyperbolic cosine of `x`.
  • std::exp `e` raised to the power `x`.
  • std::exp2 `2` raised to the power `x`.
  • std::exp2f `float32` version of `exp2`.
  • std::expf `float32` version of `exp`.
  • std::floor Rounds `x` down to the largest integer not greater than `x`. `floor(2.7) == 2.0`, `floor(-2.7) == -3.0`.
  • std::floorf `float32` version of `floor`.
  • std::hypotf `float32` version of `hypotf64`.
  • std::hypotf64 Length of the hypotenuse of a right triangle with sides `x` and `y`, i.e. `sqrt(x * x + y * y)` without the overflow.
  • std::log Natural logarithm (base `e`) of `x`.
  • std::log10 Base 10 logarithm of `x`.
  • std::log10f `float32` version of `log10`.
  • std::log2 Base 2 logarithm of `x`.
  • std::log2f `float32` version of `log2`.
  • std::logf `float32` version of `log`.
  • std::max Integer maximum. C has no standard fmax-like integer function.
  • std::maxf `float32` version of `maxf64`.
  • std::maxf64 Largest of `x` and `y`. If one of them is NaN, the other one is returned.
  • std::min Integer minimum. C has no standard fmin-like integer function.
  • std::minf `float32` version of `minf64`.
  • std::minf64 Smallest of `x` and `y`. If one of them is NaN, the other one is returned.
  • std::modf `float32` version of `modf64`.
  • std::modf64 Floating point remainder of `x / y`. The result has the sign of `x`.
  • std::pow `x` raised to the power `y`. See `pow_i64` for integers.
  • std::pow_i64 Integer power.
  • std::powf `float32` version of `pow`.
  • std::round Rounds `x` to the nearest integer, halfway cases away from zero. `round(2.5) == 3.0`, `round(-2.5) == -3.0`.
  • std::round_i64 Rounds `x` to the nearest integer, halfway cases away from zero, and returns it as an `int64`.
  • std::roundf `float32` version of `round`.
  • std::sin Sine of `x` (in radians).
  • std::sinh Hyperbolic sine of `x`.
  • std::sqrt Square root of `x`. Returns NaN if `x` is negative.
  • std::sqrtf `float32` version of `sqrt`.
  • std::tan Tangent of `x` (in radians).
  • std::tanh Hyperbolic tangent of `x`.
  • std::trunc Rounds `x` toward zero, dropping the fractional part. `trunc(2.7) == 2.0`, `trunc(-2.7) == -2.0`.
  • std::truncf `float32` version of `trunc`.
