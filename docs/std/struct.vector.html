Struct std::vector

struct std::vector<T>

Declared in src/vector.atlas

A contiguous, growable array of T.

Elements are stored in a single heap buffer of capacity slots, of which the first length are valid. Pushing past the capacity reallocates the buffer, doubling its size. The destructor deletes every element in [0, length) before freeing the buffer.

let v = std::vector<int64>::with_capacity(4);
v.push(1);
v.push(2);
let last = v.pop(); // 2
let first = *v.get(0); // 1

Indexing goes through the std::indexable conformance (get/get_mut), see below.

Fields

capacity: uint64

Number of slots in the underlying buffer. Prefer capacity(), this field will become private at one point.

length: uint64

Number of valid elements. Prefer len(), this field will become private at one point.

Methods

fun append(*this, vec: std::vector<T>) -> unit

Appends all elements from vec to the end of this vector, resizing if necessary.

The elements are moved out of vec, which is left empty. Panics if the allocation fails.

fun capacity(*const this) -> uint64

Returns the number of elements the vector can hold before it needs to reallocate.

fun insert(*this, i: uint64, val: T) -> unit

Inserts val at index i, shifting every element after it to the right.

i can be equal to len(), in which case this behaves like push. Panics if i is greater than len(), or if the reallocation fails.

fun len(*const this) -> uint64

Returns the number of elements in the vector.

fun new(ptr: *T, len: uint64) -> std::vector<T>

Creates a new vector by copying len elements starting at ptr.

The elements are copied bitwise with memcpy, so the vector ends up owning a copy of them. Be careful with types that own resources: both the original and the copy will run their destructor.

fun pop(*this) -> T

Removes and returns the last element of the vector. Panics when the vector is empty.

fun push(*this, val: T) -> unit

Appends val to the end of the vector, resizing if necessary.

Panics if the reallocation fails.

fun set(*this, index: uint64, val: T) -> unit

Sets the element at index to val. Panics on out-of-bounds access.

NB: The previous element is overwritten without running its destructor.

fun take(*this, index: uint64) -> T

Takes an element out of the vector at the specified index, shifting subsequent elements to the left.

Panics on out-of-bounds access.

fun with_capacity(capacity: uint64) -> std::vector<T>

Creates a new std::vector with the specified capacity.

The vector is empty, capacity only tells how many elements can be pushed before a reallocation happens.

Destructor

~vector()

Deletes every element in [0, length), then frees the buffer.
