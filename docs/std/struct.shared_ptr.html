Struct std::shared_ptr

struct std::shared_ptr<T>

Declared in src/shared_ptr.atlas

A pointer to a heap allocated T shared between several owners. The value is destroyed once the last owner is gone.

Every copy() increments an atomic reference count, every destructor decrements it. When it reaches zero, the value’s destructor runs and the memory is freed. The count is atomic, so the pointer can be shared across threads.

let a = std::shared_ptr<int64>::new(42);
let b = a.copy();       // use_count() == 2
let value = *a.get();   // 42

NB: The value itself isn’t protected in any way, only the reference count is. Mutating it through get_mut() from several threads at once is a data race.

Methods

fun from_raw(ptr: *T) -> std::shared_ptr<T>

Takes ownership of an already allocated T. Unsafe.

ptr must come from std::alloc<T>()/libc::malloc (or equivalent), since it will be destroyed with std::deleter<T> once the last owner is gone. Don’t free it yourself afterwards.

Returns the number of std::shared_ptr currently owning the value, or 0 if this one is null.

Destructor

~shared_ptr()

Decrements the reference count. If this was the last owner, destroys the value and frees the control block.

Conformances

extend std::shared_ptr<T> with std::copyable

Copying a std::shared_ptr doesn’t copy the value, it adds a new owner: the reference count is incremented.

fun copy(*const this) -> std::shared_ptr<T>

Returns a new std::shared_ptr to the same value and increments the reference count.

Panics if the control block is null, which shouldn’t happen.
