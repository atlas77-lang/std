std

The Atlas77 Standard Library

It is the base on which all (or at least most) atlas software is built upon. It defines a minimal set of vital core components like std::vector<T>, std::optional<T> & std::expected<T, E>

DISCLAIMER: This library isn’t stable, and will have a lot of breaking changes leading up to the 1.0 release.

What’s in there

  • Containers: std::vector<T>, std::map<K, V>, std::string
  • Sum types: std::optional<T>, std::expected<T, E>, std::either<L, R>, std::any
  • Memory: std::shared_ptr<T>, std::atomic<T>, std::alloc/std::zero_alloc, std::ptr
  • Concepts: std::comparable, std::copyable, std::default, std::hashable, std::to_string, std::indexable…
  • OS: std::file, std::directory, std::instant/std::duration, std::print/std::input
  • Math: rounding, powers, logarithms, trigonometry

The libc namespace holds the raw bindings everything above is built on, and core holds what the compiler provides.

Structs

  • Stdin Handle over the standard input stream.
  • any A type erased container. It holds a single value of any type `T`, and only gives it back if you ask for that exact `T`.
  • atomic Wrapper around an `__atomic T` type. Only allows primitive types for now.
  • directory An open directory, iterated entry by entry with `next()`.
  • duration A length of time, in nanoseconds. Can be negative.
  • either A container holding either a value of type `L` or a value of type `R`.
  • empty A zero-sized type used as a sentinel for empty states in unions.
  • expected A result-like type representing either a value `T` or an error `E`.
  • file An open file. Wrapper around a C `FILE*` that closes itself when destroyed.
  • instant A point in time, expressed in nanoseconds since the Unix epoch (January 1, 1970).
  • map A hash map from `K` to `V`, using Robin Hood open-addressing.
  • optional A lightweight container for an optional value of type `T`.
  • shared_ptr A pointer to a heap allocated `T` shared between several owners. The value is destroyed once the last owner is gone.
  • string Owned, growable, null terminated byte string.
  • vector A contiguous, growable array of `T`.
  • weak_ptr Not really implemented. This type doesn't work and should **NOT** be used at any cost rn.

Concepts

  • comparable Types with a total order. Implement `compare` and every comparison operator comes for free.
  • copyable Types that can be explicitly duplicated with `.copy()`.
  • default Types that have a sensible "zero" value, obtained through `T::default()`.
  • extendable Containers that can be extended with the content of anything `std::iterable`.
  • hashable Types that can be reduced to a `uint64` hash. Required for the keys of a `std::map<K, V>`.
  • indexable Containers that can be looked up by an index (or a key), giving back a pointer to the stored value.
  • iterable Something that can produce a `std::iterator` over its content.
  • iterator Something that yields values one at a time, until it runs out.
  • number Numeric types with a known range. Gives access to the smallest and largest value of the type.
  • primitive Marker concept for the built-in types: every integer, both floats, `char`, `bool` and `str`.
  • to_string Types that can be turned into a `std::string`.

Enums

  • FILE_MODE How a file should be opened. Maps to the C `fopen` mode strings.
  • cast_error Error cases for the `std::any` struct. Tells you why `std::any::get<T>()`, `get_mut<T>()` or `cast<T>()` failed.
  • ordering Result of a comparison between two values: `LESS`, `EQUAL` or `GREATER`.
