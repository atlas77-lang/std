Struct std::any

struct std::any

Declared in src/any.atlas

A type erased container. It holds a single value of any type T, and only gives it back if you ask for that exact T.

The value is boxed on the heap, and the std::any remembers both its core::type_info and its destructor, so it can be checked and destroyed properly without knowing T anymore.

let a = std::any::new<int64>(42);
let wrong = a.get<bool>();  // unexpected(UNEQUIVALENT_CAST)
let right = a.get<int64>(); // expect(*const int64)
let owned = a.cast<int64>(); // 42, a is now empty

Methods

fun cast(this) -> std::expected<T, std::cast_error>

Takes the value out of the container, leaving it empty. Returns a std::cast_error if the held value isn’t a T or was already taken.

After this call, has_value() returns false and any further cast<T>() returns MOVED_ANY_VALUE.

fun get(*const this) -> std::expected<*const T, std::cast_error>

Returns a const pointer to the held value, or a std::cast_error if it isn’t a T or has already been taken out.

The std::any keeps ownership of the value, the pointer is only valid as long as the std::any lives.

fun get_mut(*this) -> std::expected<*T, std::cast_error>

Returns a mutable pointer to the held value, or a std::cast_error if it isn’t a T or has already been taken out.

The std::any keeps ownership of the value, the pointer is only valid as long as the std::any lives.

fun has_value(*const this) -> bool

Returns true if the std::any still holds a value, false once it has been taken out with cast<T>().

fun new(value: T) -> std::any

Creates a new std::any holding value. The value is moved into a heap allocation owned by the std::any.

fun type(*const this) -> core::type_info

Returns the core::type_info of the held type.

fun type_id(*const this) -> uint64

Returns the type_id of the held type. Compare it with type_id<T>() to know which type this container is holding.

Destructor

~any()

Destroys then frees the contained value, if there is still one, using the destructor stored at construction time.

std::any can’t call delete on a *unit, so new<T>() stores std::deleter<T> and this calls it back.

NB: It should be possible to directly store the destructor directly using value.~T or something like that. Maybe renaming the destructor with a special case drop() method.
