Struct std::string

struct std::string

Declared in src/string.atlas

Owned, growable, null terminated byte string.

The buffer is always null terminated, so c_str() can be handed to any C function at no cost. Methods returning a std::string always return a fresh allocation, never a view into this.

let s = std::string::from_chars("Hello");
s.push_str(", World!");
std::println(s.c_str() as str);

Methods

fun c_str(*const this) -> *const uint8

Returns a pointer to the string’s data. Always valid, always NUL-terminated at data[len], a plain accessor, nothing more.

The pointer is only valid until the next mutation of the string.

fun capacity(*const this) -> uint64

Returns the capacity of the string, in usable content bytes (not counting the reserved terminator slot).

fun concat(*const this, other: *const std::string) -> std::string

Concatenates this string with another string and returns the result as a new std::string.

fun copy(*const this) -> std::string

Returns an independent copy of this string, with the same content and capacity.

fun default() -> std::string

Creates an empty string. Same as new(), exists to satisfy std::default.

fun from_chars(s_: *const uint8) -> std::string

Creates a new std::string from a null-terminated C string.

The bytes are copied, the string doesn’t keep a reference to s_.

fun is_empty(*const this) -> bool

Returns true if the string is empty, false otherwise.

fun is_whitespace(c: uint8) -> bool

Returns true if c is a space, a tab, a newline or a carriage return.

fun len(*const this) -> uint64

Returns the length of the string, in bytes, not counting the terminator.

fun new() -> std::string

Creates an empty string. It still allocates a single byte for the terminator.

fun push_char(*this, ch: char) -> unit

Appends a single char to the end of this string.

Grows the buffer if needed.

fun push_str(*this, s: *const uint8) -> unit

Appends a string slice to the end of this string.

s must be null terminated. Grows the buffer if needed.

fun substr(*const this, start: uint64, end: uint64) -> std::string

Returns a new std::string holding the bytes in [start, end).

Panics if start > end or if end is past the end of the string.

fun to_chars(*const this) -> *const uint8

Returns a string slice. Same as c_str().

fun to_lower(*const this) -> std::string

Returns a new std::string converted to lowercase. Only ASCII letters are affected.

fun to_string(val: T) -> std::string

Formats a primitive value into a new std::string.

Integers, floats, char and bool are supported. The formatting goes through libc::snprintf, so floats are printed the way C’s %f prints them. str isn’t supported yet, use from_chars instead. Prefer value.to_string() through the std::to_string concept, which calls this for you.

fun to_upper(*const this) -> std::string

Returns a new std::string converted to uppercase. Only ASCII letters are affected.

fun trim(*const this) -> std::string

Returns a new std::string with leading and trailing whitespace removed. Always an independent allocation, never a view into this, so it owns its own terminator and its own lifetime.

fun with_capacity(capacity: uint64) -> std::string

Creates a new std::string with the specified capacity.

The string is empty, capacity only tells how many bytes can be pushed before a reallocation happens.
